📧 邮件发送服务（EmailJS）

用于「忘记密码」时自动发送验证码到管理员邮箱。免费额度 200 封/月，无需后端。支持 QQ / 126 / 163 / Gmail 等所有带 SMTP 的邮箱。

📋 126邮箱配置步骤（点击展开）
第1步：登录 emailjs.com 注册免费账号
第2步：126邮箱开启 SMTP — 登录126邮箱 → 设置 → POP3/SMTP/IMAP → 开启「SMTP服务」→ 按提示用手机发短信获取授权码
第3步：EmailJS 左侧 Email Services → Add New Service → 选 Custom SMTP（或网易类）→ 填写：
  • Host: smtp.126.com
  • Port: 465（SSL）
  • Username: 你的126邮箱地址
  • Password: 授权码（不是登录密码！）
  → 保存后得到 Service ID
第4步：EmailJS 左侧 Email Templates → 新建模板，填：
  • To Email: {{to_email}}
  • Subject: {{subject}}
  • Content: 您的验证码：{{reset_code}}（30分钟内有效）
  → 保存后得到 Template ID
第5步：EmailJS 左侧 Account → 复制 Public Key
第6步：把三个 key 填到下方 → 保存 → 发送测试邮件验证
